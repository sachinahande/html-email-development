# HTML Email Development

A collection of responsive HTML email development examples, reusable patterns and best practices for building production-ready marketing emails.

## What This Repository Covers

- Responsive HTML email development
- Cross-client email compatibility
- Outlook / Microsoft Outlook rendering
- VML buttons and background images
- Gmail and Apple Mail
- Dark mode email development
- Email accessibility
- Responsive layouts
- Email QA and testing
- Figma → HTML email workflow

## Email Development

### Responsive Email

Examples of table-based layouts, fluid containers, responsive typography and mobile-friendly email components.

### Outlook / VML

Examples covering Outlook-specific rendering requirements, including:

- VML buttons
- Background images
- Outlook conditional comments
- Microsoft Office rendering considerations

### Dark Mode

Techniques for improving email rendering across light and dark mode environments.

### Accessibility

Examples and guidance for:

- Semantic structure
- Accessible links and buttons
- Alt text
- Color contrast
- Screen-reader considerations
- WCAG-oriented email practices

## Testing

Email development should be tested across major clients and environments.

Typical testing includes:

- Outlook
- Gmail
- Apple Mail
- Yahoo Mail
- Mobile email clients
- Desktop email clients
- Responsive layouts
- Dark mode
- Accessibility

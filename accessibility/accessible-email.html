Accessible Email

Email experiences designed for more people.

Accessible email development considers screen readers, keyboard users, color contrast, readable typography, meaningful links and alternative text.

Accessibility considerations

Use meaningful content structure, sufficient color contrast, descriptive alternative text for informative images and clear link labels so recipients can understand the message regardless of how they access it.

Read the Guide

Implementation notes

  • Use a valid document language.
  • Keep layout tables presentational.
  • Use meaningful heading hierarchy.
  • Provide appropriate image alternative text.
  • Use descriptive link and CTA labels.
  • Maintain readable text and sufficient contrast.
